# yt_fetcher Web パッケージ

ブラウザベースの YouTube フェッチャーで使用される FastAPI パッケージ。

## これが教えること

- HTTP 経由での小さなダウンロードワークフローの公開
- 複数の YouTube URL をバッチとして処理
- 一時作業ディレクトリからダウンロード可能なアーティファクトを生成
- CLI 形式のワークフローからのパースおよびライターコードの再利用
- コアフェッチロジックの周りに薄いウェブ境界を維持

## 最初に読むべきファイル

| ファイル | 役割 |
| --- | --- |
| `web_app.py` | FastAPI ルートとレスポンスフロー |
| `models.py` | リクエストおよび結果データ構造 |
| `parsers.py` | 字幕パースヘルパー |
| `writers.py` | 出力ファイル生成 |
| `youtube.py` | `yt-dlp` 統合 |
| `utils.py` | ファイルシステムおよびアーカイブヘルパー |

## 実践的なアイデア

1. 長時間実行されるジョブのためのステータスエンドポイントを追加する。
2. 重複または不正な URL に対する入力検証を追加する。
3. 特性テストを書いた後に CLI パッケージと共有コードを抽出する。
