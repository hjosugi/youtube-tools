# YT Fetcher

YT Fetcherは、YouTubeの英語字幕（TSV形式）、MP3オーディオ、MP4ビデオフォーマットをシームレスにダウンロードするためのシンプルでモダンなFastAPIウェブアプリケーションです。

## 機能
- **バッチ処理**: 改行で区切られた複数のYouTube URLを受け付けます。
- **複数フォーマット**: 英語字幕（TSV）、MP3（オーディオ）、MP4（ビデオ）をダウンロードします。
- **単一のZip配信**: 自動的にすべてを処理し、簡単にダウンロードできる単一の`.zip`ファイルにまとめます。
- **美しいUI**: モダンでダークテーマのレスポンシブインターフェースを特徴としています。

## ローカル開発
サーバーをローカルで実行するには：
```bash
# uvがインストールされていることを確認してください
uv sync
uv run python main.py
```
> 注: MP3抽出をローカルで動作させるには、ホストシステムに`ffmpeg`がインストールされている必要があります。

## Renderへのデプロイ
このプロジェクトは、Dockerを使用して**Render**にデプロイするために、すぐに使えるように設定されています。

### デプロイ手順：
1. このリポジトリをあなたのGitHubアカウントにプッシュします。
2. [Renderダッシュボード](https://dashboard.render.com/)にサインインします。
3. **New +**をクリックし、**Web Service**を選択します。
4. プッシュしたリポジトリを接続します。
5. Renderは自動的に`render.yaml`設定ファイルを検出し、`Dockerfile`を使用します。
6. デプロイが完了すると、RenderはFastAPIウェブサーバーを実行するDockerコンテナを起動します。ビルドが完了するのを待つと、アプリがオンラインになります！

> Renderの無料プランを使用しているため、インスタンスは15分間の非アクティブ状態の後にスピンダウンする可能性があります。新しいリクエストが到着すると、自動的にウェイクアップします（数秒かかります）。
