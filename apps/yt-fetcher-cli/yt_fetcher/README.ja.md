# yt_fetcher CLI パッケージ

スタンドアロンの `yt-fetch-cli` アプリで使用されるコア Python パッケージ。

## これが教えること

- ユーザーをインタラクティブにガイドできる便利な CLI の構築
- ダウンロードオプションを生の引数文字列ではなく、型付きデータとして保持すること
- `yt-dlp` の呼び出しを解析および出力フォーマットから分離すること
- 後で単一のバイナリにパッケージ化できる小さなモジュールを書くこと

## 最初に読むべきファイル

| ファイル | 役割 |
| --- | --- |
| `interactive.py` | 通常のユーザー向けのプロンプトファーストフロー |
| `models.py` | ダウンロードオプションのデータ構造 |
| `parsers.py` | URL と字幕の解析ヘルパー |
| `writers.py` | 字幕 TSV 出力 |
| `youtube.py` | `yt-dlp` コマンドの構築 |
| `utils.py` | 共有ファイルシステムおよびテキストヘルパー |

## 実践的なアイデア

1. 正確な計画されたダウンロードを表示するプレビューステップを追加する。
2. `youtube.py` を取得に集中させながら新しい出力形式を追加する。
3. 複数の URL 入力用のパーサーテストを追加する。
