# gen_subtitle パッケージ

バイリンガル字幕ハンズオンアプリの背後にあるPythonパッケージ。

## これが教えること

- CLIワークフローを小さなモジュールに分割すること
- 字幕フォーマットをドメインオブジェクトにパースすること
- 出力を決定論的に保ちながらバッチで翻訳すること
- TSV、SRT、およびMarkdownの学習資料を書くこと
- インタラクティブプロンプトをコア処理から分離すること

## 最初に読むべきファイル

| ファイル | 役割 |
| --- | --- |
| `cli.py` | コマンドラインエントリーポイントと引数マッピング |
| `interactive.py` | フラグを使用したくないユーザーのためのガイド付きプロンプトフロー |
| `models.py` | 字幕セグメントと翻訳データ構造 |
| `parsers.py` | 字幕のパース |
| `translators.py` | 翻訳バックエンドとバッチ処理 |
| `writers.py` | TSV、SRT、およびMarkdown出力 |
| `youtube.py` | `yt-dlp`統合 |

## ハンズオンアイデア

1. 計画されたダウンロードと出力名を印刷するドライランモードを追加する。
2. 手動学習のためのTODOマーカーを残す翻訳者実装を追加する。
3. フォーマットを変更する前に、パースとライター出力に関するテストを追加する。
